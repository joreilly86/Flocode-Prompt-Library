# Compact and Continue

**Purpose:** Condense a lengthy technical conversation into a focused handoff document. Use this when approaching context limits or when you need to start a fresh session while preserving all critical information.

```
Generate a technical handoff summary with:

1. Objective and scope
2. Current status and key decisions made
3. Critical design parameters, constraints, and assumptions
4. Outstanding items requiring resolution (with priority if applicable)
5. Next logical steps

Omit iterative discussion and abandoned approaches. Focus on actionable information. Provide complete context for immediate continuation by a peer professional in a new session.
```
